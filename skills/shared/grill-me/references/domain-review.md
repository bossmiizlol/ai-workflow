# Document-backed review

Use the same calibration and question loop as grill-me. Locate the project's
existing domain definitions, contracts and decision records before asking about
terms. Compare the documented rule, current code and proposed change. Resolve
ambiguous vocabulary with concrete examples and cite the conflicting sources.
Record decisions where the current project requires. Respect read-only files;
do not invent a new glossary or decision-log system without need.
